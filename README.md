# UMax Studios — website concept

Static redesign demo for UMax Studios. The site is plain HTML, CSS, and JavaScript and is ready to publish with GitHub Pages.

## Publish with GitHub Pages

1. Create a new repository on GitHub.
2. Upload `index.html`, `README.md`, and `.nojekyll` to the repository's top level, then commit the files to the `main` branch.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for GitHub Pages to finish publishing. The Pages address will appear on the repository's Pages settings screen.

No build command or GitHub Actions workflow is required. The site entry point is `index.html`.

## Before sharing publicly

- The gallery photos are illustrative stock images loaded from Unsplash URLs. Replace them with UMax photographs approved for website use.
- Google Fonts load from Google Fonts; system font fallbacks are included.
- The review section contains draft paraphrase copy. Replace it with a verified, attributed review or remove it.
- Confirm business details and remove concept labels only after client approval.
- The call and WhatsApp links are active. The site does not collect or store form submissions.
